## TOR_VM

(Django) Pet-проект интернет магазин стоматологических товаров

## О проекте

В ходе разработки проекта:

  * Написан парсер для сбора информации о товарах с применением библиотеки beautifulsoup4
  * Настроена админ-панель для управления данными
  * Добавлена возможность регистрации и авторизации пользователей
  * Добавлен личный кабинет и возможность редактировать профиль
  * Добавлена возможность восстановления пароля через электронную почту
  * Добавлена корзина для авторизованных пользователей и гостей
  * Добавлена форма обратной связи

## Технологии

- python 3.11
- Django 4.2.4
- PostgreSQL
